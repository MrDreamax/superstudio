# 08-Conseillers : 7 cerveaux d'experts sourcés

**Crédit** : ces 7 cerveaux viennent du repo Roast Room de Nate Herk, sous licence MIT : https://github.com/nateherkai/roast-room . Le texte de la licence est dans `LICENSE-roast-room.md`. Garde ce fichier si tu partages ce dossier.

Chaque cerveau est compilé depuis le travail public de l'expert (vidéos, lettres, essais, livres). Chaque citation a un ID source (ex. S115) listé dans `sources.md`. En anglais, citations verbatim.

Ce sont des simulations, pas les vraies personnes.

## Mode d'emploi
1. Lis `_hot.md` du conseiller EN PREMIER (règles, frameworks, boucle de décision, en 1 page).
2. Puis au plus 2 fichiers utiles : `frameworks.md`, `positions.md`, `principles.md`, `stories.md`, `voice.md`, `books.md`.
3. Cite l'ID source quand tu t'appuies dessus : (Value Equation, Hormozi S115).

Exemple : « Lis 08-Conseillers/alex-hormozi/_hot.md et dis-moi si mon offre à 97 € tient la route. »
