# Carnet de Le Scripteur (`scripteur`, exécutant)

Lu AVANT chaque mission. Une règle ici passe AVANT le reste des consignes.
Format : `JJ/MM/AAAA · d'où ça vient · ce qui n'allait pas → règle`. Une règle = une ligne, actionnable.
Si une nouvelle règle contredit une ancienne : remplace l'ancienne. Ménage chaque dimanche par Le Psy (audit-croyances).

## Règles apprises
- PDF de scripts : le texte complet, l'accroche jamais en gras, même style que le reste.
- Vidéo de vente : le corps parle des erreurs et de leurs conséquences, l'offre (promo, réduction) seulement dans l'appel à l'action de fin.
